           기상청 단기예보 대시보드 (KMA Weather Dashboard) 
                     컴포넌트 문제점 분석 및 디자인 개선 보고서

1. 프로젝트 개요 & 수정 배경
--------------------------------------------------------------------------------
본 보고서는 ./assets/mockup.png 시안 디자인을 바탕으로 프로젝트 전체 컴포넌트 구조,
스타일링, 상태 관리(Recoil) 및 UX 기능을 전면 분석하고 개선한 내용을 정리한 문서입니다.

기존 코드 베이스는 모바일용 500px 제한 레이아웃, 라이트 테마 잔재, 컴포넌트 누락 및
단순 세로 나열 등 시안과 상당한 차이가 존재하였습니다. 이를 완벽히 보완하여 시안과 동일한
고품질의 인디고 다크 테마 대시보드로 리팩토링을 완료했습니다.


2. 시안(mockup.png) 대비 기존 코드 문제점 분석 (Issues Identified)
--------------------------------------------------------------------------------
(1) 글로벌 레이아웃 및 테마 배경 문제
    - 기존 `_common.scss`의 `#root { max-width: 500px; }` 및 흰색 배경($white) 설정으로
      인해 대시보드가 모바일 폭으로 좁게 축소되는 문제 발생.
    - `index.css` 및 `App.css`에 Vite 스타터 템플릿 코드(라이트/다크 혼용 변수) 잔재.

(2) 상단 네비게이션 헤더 (Header Bar) 누락
    - 시안 최상단의 브랜드 로고, "KMA Short-Term Forecast Demo", "기상청 단기예보 대시보드"
      타이틀 및 "API 새로고침" 버블 버튼 누락.

(3) 좌측 메인 히어로 카드의 상태 연동 및 디자인 미흡
    - 시안의 `LIVE API READY` 네온 그린 배지 및 레이더 애니메이션 그래픽 누락.
    - 하단 관심 지역 카드(서울 강남구, 부산 해운대구, 제주 제주시) 클릭 시 전역 상태(contentState)가
      업데이트되지 않고 콘솔 출력만 실행되던 버그.

(4) 지도 프리뷰 및 2x2 현황 카드 비주얼 부족
    - 현재 선택 위치 지도 프리뷰의 블루프린트 격자 패턴(Grid Mesh), nx/ny 좌표 뱃지, 
      위치 핀 펄스 애니메이션 미비.
    - 2x2 기상 현황 카드(기온, 강수확률, 습도, 풍속)의 원형 아이콘 버블 및 가시성 부족.

(5) 시간대별 차트 영역 (TimeTable) 레이아웃 오류
    - 라인 차트(기온 & 강수확률)와 바 차트(풍속)가 시안과 달리 단일 컬럼 세로로 단순 나열됨.
    - 바 차트(TimeWindy) 각 기둥 상단에 수치 텍스트가 표시되지 않음.

(6) 하단 3개 안내 카드 (Bottom Info Row) 누락
    - 시안 맨 하단의 `API Flow`, `UX 포인트`, `데이터 갱신` 3개 정보 카드가 미구현 상태였음.


3. 컴포넌트별 상세 개선 및 수정 내용 (Detailed Improvements)
--------------------------------------------------------------------------------
[1] 글로벌 스타일 & 레이아웃 (src/index.css, src/styles/base/_common.scss)
    - #0b0e1b 깊은 인디고 다크 배경 및 전체 화면 통일.
    - #root의 500px 제한 해제, 1360px 중앙 정렬 대시보드 레이아웃 구축.

[2] 상단 헤더 컴포넌트 (src/components/organism/header/header.tsx)
    - 기상청 단기예보 대시보드 브랜딩 헤더 신규 생성.
    - Recoil useRecoilRefresher_UNSTABLE을 연동한 'API 새로고침' 필 버튼 구현.

[3] 좌측 메인 히어로 (src/components/organism/weatherData/weatherData.tsx)
    - `✨ 지도 좌표 → nx, ny 변환 → 단기예보 조회` + `LIVE API READY` 뱃지 적용.
    - 시안 타이틀 "날씨 데이터를 화려한 시각화로." 적용.
    - 관심 지역 카드(otherWeatherList) 클릭 시 Recoil contentState(location, nx, ny)가
      자동 변경되어 우측 지도/날씨/차트 데이터가 실시간 갱신되도록 연결.
    - 선택된 카드에 민트색 글로우 테두리(is-active) 스타일 부여.
    - 우측 하단 레이더 서클 아이콘 및 링 그래픽 완성.

[4] 지도 프리뷰 (src/components/molecules/presentLocate/presentLocate.tsx)
    - 격자선 패턴(Grid Mesh), nx/ny 좌표 뱃지, "제주 제주시" 핀 펄스 애니메이션 구현.
    - 상단 GPS 버튼 클릭 시 브라우저 HTML5 Geolocation 위경도를 기상청 격자로 자동 변환하는 기능 구현.

[5] 2x2 현황 카드 (src/components/molecules/presentWeather/presentWeather.tsx)
    - 현재 기온(TMP), 강수확률(POP), 습도(REH), 풍속(WSD)에 선명한 SVG 아이콘 버블 배치.

[6] 2열 차트 시각화 (src/components/organism/timeTable/timeTable.tsx)
    - TimeTemperature(라인 차트)와 TimeWindy(바 차트)를 가로 2열 그리드로 배치.
    - TimeTemperature: 기온(민트 cyan), 강수확률(퍼플) 커스텀 범례 탭 및 둥근 곡선 포인트 적용.
    - TimeWindy: Chart.js 커스텀 플러그인을 작성하여 바 상단에 풍속 수치(2.1, 2.8 등) 직관적 표시,
      민트 그라데이션 기둥 디자인 반영.

[7] 하단 3개 안내 카드 (src/components/organism/bottomInfo/bottomInfo.tsx)
    - API Flow, UX 포인트, 데이터 갱신 안내 카드를 3열 그리드로 신규 생성 및 수록.
